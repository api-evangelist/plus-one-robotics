# Plus One Robotics

> Warehouse-automation company (San Antonio, TX; founded 2016) building AI-powered
> computer-vision software and robotic work cells for parcel handling, depalletizing,
> palletizing and induction. PickOne is the perception system that tells a robot arm
> how to grasp each item and verifies placement; Yonder is the supervised-autonomy
> layer where remote human "Crew Chiefs" take over on exceptions. DepalOne and
> InductOne are the packaged work cells. Plus One Robotics publishes NO public
> developer program, API reference, or machine-readable API contract — this file is
> generated by API Evangelist from the company's public web surface, not from a
> provider-published llms.txt.
